# E-Commerce Sales & Customer Analysis 

📊 Project Overview

This project analyzes an E-Commerce business to understand sales performance, customer behavior, product performance, category trends, and inventory.

The project follows an end-to-end data analytics workflow using Excel, MySQL and Power BI, from data cleaning and transformation to business insights and recommendations.

🛠️ Tools Used

- Excel & Power Query – Data cleaning, transformation, formulas, Pivot Tables and MIS Dashboard
- MySQL – Data analysis and business queries
- Power BI & DAX – Data modeling, KPI development and interactive dashboards

 🔄 Workflow

Data Cleaning → Data Transformation → SQL Analysis → Data Modeling → KPI Development → Dashboard → Business Insights

 📈 Key Metrics

- Revenue: $9.08M
- Orders: 20,000
- Customers: 5,000
- Units Sold: 87,704
- Repeat Customer Rate: 84.86%

 🔍 Key Insights

- Electronics, Home & Kitchen and Sports & Fitness contributed approximately **73.5% of total revenue**.
- Non-Stick Pan was one of the strongest products by revenue and sales volume.
- 531 customers (10.62%) had never placed an order.
- 12 products were out of stock.
- Revenue and order volume showed a noticeable decline after August.

💡 Business Recommendations

- Investigate the reasons behind the post-August sales decline.
- Improve inventory planning for high-demand products.
- Increase customer value through cross-selling and upselling.
- Target never-purchased customers with first-purchase campaigns.
- Monitor dependency on high-performing categories and products.
